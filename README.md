# MARIO Tutorials

Read the tutorials at [tutorials.marioproject.com](https://tutorials.marioproject.com/).
Each exercise provides a readable notebook, downloadable materials and the exact
source revision used for its published page.

The collection includes tutorials maintained in this repository and exercises
maintained in other MARIO repositories. MRIO disaggregation is maintained in
[MRIO-disaggregation-model](https://github.com/it-is-me-mario/MRIO-disaggregation-model).
Its existing source and download links remain available there.

`site/catalog.json` registers each tutorial's source and materials. The site
imports external content at a recorded commit and renders the notebooks without
running their calculations. Published notebook downloads retain the source cells
and remove stored outputs.

See [CONTRIBUTING.md](CONTRIBUTING.md) for notebook maintenance and
[site/README.rst](site/README.rst) for builds, publication and source refreshes.
